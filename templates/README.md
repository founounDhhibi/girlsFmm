# Templates

Jinja templates for the Flask UI.

## Files

- `index.html`: Analyzer page where messages are submitted.
- `result.html`: Result page for decision output (if routed).
- `dashboard.html`: Operational dashboard with stats and pending queue.
- `audit_log.html`: Full audit trail view.

## Notes

These templates depend on `static/style.css` and `static/js/main.js`.
